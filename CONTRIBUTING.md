# Contributing

Thanks for helping improve the BookMac replicas. Corrections, build notes, photos of your own build, design fixes and documentation improvements are all welcome.

This is a hobbyist work in progress (see the README). The most useful contributions are often reports of what didn't match: a wrong dimension, a pinout error, a part that didn't fit.

## How to contribute

- **Found a problem or have a question?** Open an issue. Say which unit (BookMac or BookMac Mini) and which file or document it concerns.
- **Have a change?** Open a pull request.
  - Keep each pull request to one topic.
  - Describe what you changed and how you checked it, for example "printed and test-fitted", "measured with calipers" or "checked against the datasheet".
  - Name new files in lowercase with hyphens, matching the existing ones.

### Please don't submit

- Mac OS system software, Macintosh ROM images or other copyrighted software.
- Apple logo artwork, case labels or other trademark artwork.
- Photos that still carry GPS or other location metadata. Strip EXIF data before adding images.
- Files you don't have the right to share.
